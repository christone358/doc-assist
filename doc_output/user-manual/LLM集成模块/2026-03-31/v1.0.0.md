# LLM 集成模块用户使用手册

## 4. 软件操作指南

### 4.1 LLM 集成模块

LLM 集成模块是 NextAgent Doc Assistant 系统的核心组件之一，负责集成多种大语言模型（如 DeepSeek-V3、QWen-max 等），为系统提供自然语言理解和文档生成能力。本模块支持多模型配置管理、运行时模型切换和流式输出。

#### 4.1.1 配置和管理 LLM 模型

##### 4.1.1.1 功能概述
本功能允许系统管理员或用户在系统中添加、编辑或删除 LLM 模型的配置信息，包括 API 地址、访问令牌（Token）、模型名称、温度参数等。配置完成后，Agent 将使用这些配置与对应的 LLM 服务进行通信。

##### 4.1.1.2 前置条件
- 您需要拥有系统配置页面的访问权限（通常是管理员角色）。
- 您需要提前从 LLM 服务提供商（如 DeepSeek、通义千问）处获取有效的 API 访问密钥（Token）和 API 端点地址。

##### 4.1.1.3 操作步骤
1.  **进入配置页面**：登录系统后，在左侧导航栏或系统设置菜单中，找到并点击【系统配置】>【模型管理】（具体路径待确认）。
2.  **查看模型列表**：进入“模型管理”页面后，您将看到当前已配置的所有 LLM 模型列表，包括模型名称、提供商、状态等信息。
3.  **添加新模型**：
    a. 点击页面上的【添加模型】或【新建】按钮。
    b. 在弹出的“添加模型配置”对话框中，填写以下信息：
        - **模型名称**：输入一个易于识别的名称，如“DeepSeek-V3-主力模型”。
        - **提供商**：从下拉列表中选择模型提供商，如“DeepSeek”或“QWen”。
        - **模型标识**：输入该提供商下的具体模型标识符，如 `deepseek-chat`、`qwen-max`。
        - **API 地址**：输入该模型 API 的完整端点 URL。
        - **API Token**：在“API Token”输入框中粘贴您的访问密钥。
        - **默认参数**：设置模型的默认调用参数，如温度（Temperature）、最大 Token 数等。
    c. 点击【测试连接】按钮，验证配置是否正确，API 是否可访问。
    d. 测试通过后，点击【保存】按钮。
4.  **编辑现有模型**：
    a. 在模型列表中找到需要修改的模型。
    b. 点击该行右侧的【编辑】按钮或图标。
    c. 在编辑对话框中修改相应配置信息。
    d. 点击【保存】按钮。
5.  **删除模型**：
    a. 在模型列表中找到需要删除的模型。
    b. 点击该行右侧的【删除】按钮或图标。
    c. 系统将弹出确认对话框，提示“删除后该模型将不可用，是否继续？”。
    d. 确认无误后，点击【确定】按钮。

**警告**：删除模型配置是不可逆操作。如果该模型是当前对话正在使用的模型，删除后可能导致对话异常。请谨慎操作。

##### 4.1.1.4 输出/结果
- **添加/编辑成功**：页面将刷新，新模型会出现在列表中，或已修改模型的配置信息被更新。系统可能显示“配置保存成功”的提示。
- **测试连接成功**：系统提示“连接测试成功”，表明配置的 API 地址和 Token 有效。
- **删除成功**：该模型配置将从列表中消失。

##### 4.1.1.5 异常处理

| 异常现象 | 可能原因 | 处理方法 |
| :--- | :--- | :--- |
| 点击【测试连接】后提示“连接失败”或“认证失败”。 | 1. API 地址填写错误。<br>2. API Token 无效或已过期。<br>3. 网络问题导致无法访问目标 API 服务。 | 1. 检查并修正 API 地址。<br>2. 确认 Token 是否正确且未过期。<br>3. 检查本地网络或代理设置。 |
| 保存配置时提示“模型名称已存在”。 | 试图添加或修改的模型名称与现有配置重复。 | 修改为一个新的、唯一的模型名称。 |
| 无法找到【模型管理】菜单或页面。 | 当前登录账号权限不足。 | 联系系统管理员获取配置权限。 |
| 删除模型时提示“该模型正在被使用，无法删除”。 | 当前有活跃对话或系统任务正在使用该模型。 | 等待相关任务结束，或切换到其他模型后再尝试删除。 |

#### 4.1.2 在对话中切换 LLM 模型

##### 4.1.2.1 功能概述
本功能允许用户在单次对话过程中，随时切换到另一个已配置的 LLM 模型。切换后，后续的用户请求和 Agent 的回复都将由新选择的模型处理。这便于用户对比不同模型的输出效果，或在某个模型服务不稳定时快速切换。

##### 4.1.2.2 前置条件
- 系统中已配置至少两个可用的 LLM 模型。
- 您处于一个活跃的对话会话中。

##### 4.1.2.3 操作步骤
1.  **打开对话界面**：在 Web UI 主界面，进入或创建一个新的对话。
2.  **定位模型切换控件**：在对话输入框附近或对话设置区域，找到模型选择器（可能显示为下拉菜单或按钮，标签如“当前模型：DeepSeek-V3”）。
3.  **选择新模型**：点击模型选择器，从下拉列表中浏览并选择另一个已配置的模型（如“QWen-max”）。
4.  **确认切换**：系统可能会弹出提示框，询问“切换模型将影响后续回复，是否确认？”。点击【确认】或【切换】按钮。

**注意**：模型切换仅对切换**之后**发送的消息生效。切换前已生成的历史消息不会改变。

##### 4.1.2.4 输出/结果
- 模型选择器显示的名称会更新为您新选择的模型。
- 系统可能在聊天区域发送一条系统提示，例如：“已切换至 QWen-max 模型”。
- 您接下来发送的消息，将由新的模型进行处理和回复。

##### 4.1.2.5 异常处理

| 异常现象 | 可能原因 | 处理方法 |
| :--- | :--- | :--- |
| 模型选择器下拉列表为空或只有当前一个模型。 | 系统中只配置了一个模型，或其它模型配置状态异常（如禁用、连接失败）。 | 前往【模型管理】页面检查并确保有多个可用模型。 |
| 切换模型后，新消息长时间无响应或报错。 | 新切换的模型配置有误或服务暂时不可用。 | 1. 检查该模型的配置（API、Token）。<br>2. 切换回之前可用的模型。 |
| 切换时无任何提示，但后续回复风格未变。 | 切换可能未成功，或前端缓存了旧模型状态。 | 刷新页面，并重新尝试切换操作。 |

#### 4.1.3 理解流式输出

##### 4.1.3.1 功能概述
LLM 集成模块支持 Server-Sent Events (SSE) 流式输出。这意味着当 Agent 生成较长回复时，文本会像打字一样逐词、逐句地实时显示在聊天界面中，而不是等待全部生成完毕后再一次性显示。这提升了交互的实时感和用户体验。

##### 4.1.3.2 操作说明
此功能由系统自动启用，无需用户手动配置。当您发送一条请求后：
1.  聊天界面会立即显示一个“正在输入”的指示（如闪烁的光标或加载动画）。
2.  回复内容开始逐段出现。
3.  您可以在内容生成过程中随时阅读已输出的部分。
4.  生成完成后，指示器消失。

##### 4.1.3.3 异常处理

| 异常现象 | 可能原因 | 处理方法 |
| :--- | :--- | :--- |
| 流式输出中断，回复不完整。 | 1. 网络连接不稳定。<br>2. 服务器端生成过程出错。<br>3. 模型 API 响应超时。 | 1. 检查网络连接。<br>2. 尝试重新发送问题。<br>3. 如果频繁发生，可能是模型服务问题，可尝试切换模型。 |
| 没有流式效果，回复等待很久后一次性显示。 | 1. 当前模型或配置不支持流式输出。<br>2. 浏览器或前端设置禁用了 SSE。 | 1. 确认模型配置中流式输出选项已开启（待确认配置项）。<br>2. 检查浏览器控制台是否有错误。 |

### 4.2 API 接口使用指南（概要）

**说明**：由于 `interfaces` 详情暂未提供，以下为基于模块功能的通用性 API 使用概述。具体端点、请求/响应格式需后续补充。

#### 4.2.1 核心接口方向
LLM 集成模块主要提供以下类型的接口供系统内部（如 Agent 模块）调用：
1.  **模型调用接口**：接收用户输入和上下文，调用指定的 LLM 模型，返回生成的文本（支持流式）。
2.  **配置管理接口**（可能为内部接口）：供前端“模型管理”页面调用，用于增删改查模型配置。
3.  **模型列表接口**：提供给前端，获取当前所有可用模型的列表，用于模型切换器下拉菜单。

#### 4.2.2 调用模型生成文本（示例概念）
```http
POST /api/llm/generate
```
**请求体**可能包含：
```json
{
  "model_id": "deepseek-v3-config-1",
  "messages": [
    {"role": "user", "content": "请帮我写一份项目计划书。"}
  ],
  "stream": true,
  "parameters": {
    "temperature": 0.7,
    "max_tokens": 2000
  }
}
```
**响应**：当 `stream: true` 时，连接将保持打开，以 SSE 格式持续返回文本块。

### 4.3 常见问题解决（FAQ）

**Q1: 系统提示“无可用模型”或“模型服务错误”，怎么办？**
A1:
1.  首先检查【模型管理】中是否有已启用且测试通过的模型配置。
2.  如果配置存在，检查模型服务商的 API 状态页面，确认其服务是否正常。
3.  检查部署 NextAgent 的服务器的网络，确保其可以访问外部的模型 API 地址。

**Q2: 切换模型后，为什么 Agent 好像“忘记”了之前的对话内容？**
A2: 模型切换通常不会清除对话上下文。如果出现此现象，可能是新模型的上下文长度限制比旧模型小，导致更早的历史消息被截断。这是模型自身特性，建议在单次对话中尽量使用同一模型完成一个完整任务。

**Q3: 流式输出时，如何复制完整的回复内容？**
A3: 等待流式输出完全结束后，聊天消息旁通常会显示【复制】按钮。点击即可复制完整内容。如果界面未提供该按钮，您可以手动选择文本进行复制。

**Q4: 我可以自己添加 OpenAI 或 Claude 的模型吗？**
A4: LLM 集成模块的设计支持多模型。理论上，只要该模型提供兼容的 API（如 OpenAI-API 兼容格式），并在此模块中实现对应的调用适配器，即可添加。具体添加方法需要参考开发文档或模块的扩展指南（待补充）。
