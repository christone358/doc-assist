# 业务保障管理系统终端资产管理用户使用手册

# 4. 软件操作指南

### 4.1 终端资产管理
本模块面向资产管理员，提供对终端资产的统一纳管与监控能力。通过本模块，管理员可以完成终端资产的登记、查询、编辑、导入及详情查看等核心管理操作，实现对终端资产全生命周期的有效监控与管理。

#### 4.1.1 终端资产列表
##### 4.1.1.1 功能概述
终端资产列表是资产管理的主工作台，集中展示所有已登记的终端资产信息。通过此功能，资产管理员可以快速查询、筛选资产，并执行资产登记、导入、编辑及查看详情等核心管理操作。

##### 4.1.1.2 前置条件
1.  用户已登录业务保障管理系统。
2.  用户角色为“资产管理员”，具备终端资产管理模块的操作权限。
3.  需确认界面路径。

##### 4.1.1.3 操作步骤
1.  **设备资产查询**：
    1.  进入终端资产管理模块主页面。
    2.  在列表上方或侧边的查询区域，输入或选择查询条件（如资产编号、设备类型、使用状态等）。待补充字段规则。
    3.  点击【查询】按钮，系统将根据条件筛选并刷新列表，展示符合条件的资产记录。

2.  **资产登记**：
    1.  在资产列表页面，点击【登记】或【新增】按钮，弹出资产登记表单对话框。
    2.  在表单中填写资产信息，如资产编号、设备名称、型号、序列号、使用部门、责任人等。待补充字段规则。
    3.  填写完毕后，点击【提交】或【保存】按钮。

3.  **资产导入**：
    1.  在资产列表页面，点击【导入】按钮，弹出资产导入对话框。
    2.  点击【选择文件】或【上传】按钮，选择符合模板格式的资产数据文件（如Excel文件）。待补充字段规则。
    3.  点击【开始导入】或【确认上传】按钮，系统将解析并导入文件中的数据。

4.  **资产编辑**：
    1.  在资产列表中，找到需要修改的资产记录。
    2.  点击该记录对应的【编辑】按钮或操作链接，弹出资产编辑表单对话框。
    3.  在表单中修改需要变更的资产信息。待补充字段规则。
    4.  修改完毕后，点击【保存】按钮。

5.  **资产详情**：
    1.  在资产列表中，找到需要查看的资产记录。
    2.  点击该记录对应的【详情】按钮或资产编号链接，进入资产详情页面。
    3.  在详情页面中，可以查看该资产的全部属性信息、关联记录及历史操作日志。

##### 4.1.1.4 输出/结果
1.  **查询结果**：列表刷新，仅展示符合查询条件的资产记录。
2.  **登记/导入/编辑成功**：系统弹出“操作成功”提示。待补充系统反馈文案。资产列表自动刷新，新增或修改的记录将显示在列表中。
3.  **进入详情页**：页面跳转至资产详情页，展示选定资产的完整信息。截图待补充。

##### 4.1.1.5 异常处理
| 异常现象 | 可能原因 | 处理方法 |
| :--- | :--- | :--- |
| 点击【查询】后列表无变化或报错 | 查询条件格式不正确或系统异常 | 1. 检查查询条件输入是否符合要求。<br>2. 清除条件后重新查询，若仍异常，请联系系统管理员。 |
| 资产登记/编辑时，点击【保存】按钮无反应或提示失败 | 必填信息未填写、数据格式错误或信息重复（如资产编号重复） | 1. 检查表单中所有必填项（通常标有*号）是否已填写。<br>2. 检查输入内容是否符合字段规则（如长度、格式）。<br>3. 检查关键信息（如资产编号）是否与已有记录冲突。 |
| 导入文件时提示“文件格式错误”或“数据校验失败” | 上传的文件非指定模板格式，或模板内数据不符合系统要求 | 1. 下载系统提供的标准导入模板。<br>2. 严格按照模板格式和要求填写数据。<br>3. 重新选择正确的文件进行导入。 |
| 无法找到【编辑】或【详情】按钮 | 当前用户权限不足，或该资产记录状态不允许编辑 | 1. 确认当前登录账号是否具备相应操作权限。<br>2. 联系系统管理员确认资产状态。 |

##### 4.1.1.6 警告/注意
1.  **资产导入**：批量导入操作将直接新增或更新系统数据，请在导入前务必核对文件内容的准确性，错误的数据可能导致资产信息混乱。
2.  **资产编辑**：修改关键信息（如资产编号、责任人）可能影响与该资产相关的业务流程或统计报表，请谨慎操作。
