# 业务保障管理系统云主机资产管理用户使用手册

# 4. 软件操作指南

### 4.1 云主机资产管理
本模块面向资产管理员，提供对混合云环境中云主机资产的统一纳管能力。通过自动化同步、手动导入与更新、资产详情查看等功能，实现对云主机资产全生命周期的集中监控与管理，确保资产信息的准确性和时效性。

#### 4.1.1 云服务资产列表
##### 4.1.1.1 功能概述
云服务资产列表是云主机资产管理的主界面，用于集中展示和管理所有已纳管的云主机资产。资产管理员可在此进行资产查询、通过API自动同步资产、手动导入或更新资产信息，并查看资产详情。

##### 4.1.1.2 前置条件
1.  用户已登录业务保障管理系统。
2.  用户具备“资产管理员”角色或相应的云主机资产管理权限。
3.  需确认界面路径。

##### 4.1.1.3 操作步骤
1.  **设备资产查询**：
    1.  进入“云主机管理”页面。
    2.  在查询区域，可根据主机名称、IP地址、设备序列号、MAC地址、所属网段、所属机房、云平台等条件进行筛选。
    3.  输入查询条件后，点击查询按钮，系统将展示符合条件的云主机资产列表。

2.  **API自动同步**：
    1.  在“云主机管理”页面，找到并点击【API自动同步】或类似功能按钮。
    2.  系统将自动调用预设的云平台API接口，拉取最新的云主机资产信息并更新至本系统。
    3.  同步完成后，系统将刷新资产列表，显示同步结果。

3.  **资产导入**：
    1.  在“云主机管理”页面，点击【资产导入】或类似功能按钮。
    2.  在弹出的对话框中，选择或拖拽符合模板格式的资产数据文件（如Excel、CSV）。
    3.  确认导入文件后，系统将解析文件内容并批量创建或更新云主机资产记录。
    4.  导入完成后，系统将提示导入结果（成功/失败数量），资产列表将相应更新。

4.  **资产更新**：
    1.  在“云主机管理”页面的资产列表中，定位到需要更新的目标资产记录。
    2.  点击该资产记录对应的【编辑】或【更新】操作按钮。
    3.  在弹出的编辑对话框中，修改需要更新的资产信息字段，如主机名称、描述、责任人等。
    4.  修改完成后，点击【确定】或【保存】按钮提交更新。

5.  **资产详情**：
    1.  在“云主机管理”页面的资产列表中，定位到目标资产记录。
    2.  点击该资产记录对应的【详情】操作按钮。
    3.  系统将跳转至“云主机详情”页面，展示该资产的完整信息。

##### 4.1.1.4 输出/结果
-   **查询**：页面刷新，展示符合筛选条件的云主机资产列表。
-   **API自动同步**：系统提示“同步任务已启动”或“同步完成”，待补充系统反馈文案。资产列表自动刷新，显示同步后的最新数据。
-   **资产导入**：系统弹出导入结果提示（如“成功导入X条，失败Y条”），待补充系统反馈文案。资产列表刷新，新增或更新的资产记录将显示在列表中。
-   **资产更新**：系统弹出“更新成功”提示，待补充系统反馈文案。列表中该资产的信息将更新为修改后的内容。
-   **查看详情**：页面跳转至“云主机详情”页，展示选中资产的完整属性信息。

##### 4.1.1.5 异常处理
| 异常现象 | 可能原因 | 处理方法 |
| :--- | :--- | :--- |
| 查询无结果 | 输入的查询条件过于严格或资产不存在 | 检查并放宽查询条件，或确认资产是否已录入系统。 |
| API同步失败 | 网络连接异常、云平台API接口变更或凭证失效 | 检查网络连接，确认云平台API配置（如访问地址、密钥）是否正确有效。 |
| 资产导入失败，提示“文件格式错误” | 导入文件不符合系统要求的模板格式 | 下载系统提供的标准模板，按照模板格式整理数据后重新导入。 |
| 资产导入失败，提示“数据校验失败” | 导入文件中的数据存在必填项为空、格式错误或与系统已有数据冲突 | 根据系统提示的错误信息，修正文件中对应行的数据，然后重新导入。 |
| 更新资产时提示“保存失败” | 当前编辑的资产信息已被其他用户修改，或存在数据冲突 | 刷新页面获取最新数据后，重新进行编辑操作。 |

##### 4.1.1.6 警告/注意
-   **API自动同步**：执行同步操作会覆盖本系统中通过该API源同步的资产信息。请确保在业务低峰期执行，并关注同步日志，确认同步结果。
-   **资产导入**：批量导入操作具有覆盖性。导入前请务必核对数据准确性，建议先进行小批量测试导入。
-   **资产更新**：更新资产关键信息（如IP、责任人）可能影响与该资产关联的监控、告警或任务流程，请谨慎操作。
