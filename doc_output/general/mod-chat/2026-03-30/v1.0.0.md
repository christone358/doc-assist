# NextAgent Doc Assistant 对话功能用户使用手册

## 4. 软件操作指南

### 4.1 对话管理

#### 4.1.1 创建新对话

##### 4.1.1.1 功能概述
创建新的对话会话，用于开始一次新的文档编写或咨询任务。每个对话将独立维护上下文和历史记录。

##### 4.1.1.2 前置条件
- 已成功登录 NextAgent Doc Assistant 系统
- Web UI 界面已正常加载

##### 4.1.1.3 操作步骤
1. 在 Web UI 主界面左侧导航栏中，点击【新建对话】按钮
2. 系统将自动创建一个新的对话会话，并显示在左侧对话列表中
3. 新对话的默认名称为"新对话"或基于首次消息内容自动生成

##### 4.1.1.4 输出/结果
- 右侧主聊天区域清空，准备接收用户输入
- 左侧对话列表新增一个对话项
- 对话状态标记为"进行中"
- 系统显示欢迎消息或等待用户输入提示

##### 4.1.1.5 异常处理
| 异常现象 | 可能原因 | 处理方法 |
|---------|---------|---------|
| 【新建对话】按钮不可点击 | 网络连接异常或系统未初始化完成 | 检查网络连接，刷新页面后重试 |
| 创建后对话列表未更新 | 本地存储或同步异常 | 刷新页面，查看对话是否已创建 |
| 系统提示"创建失败" | 服务器端对话管理服务异常 | 稍后重试，或联系系统管理员 |

#### 4.1.2 切换对话

##### 4.1.2.1 功能概述
在不同对话会话之间切换，查看或继续之前的对话内容。

##### 4.1.2.2 前置条件
- 系统中存在至少两个对话会话
- 当前处于任意对话界面

##### 4.1.2.3 操作步骤
1. 在左侧对话列表中，找到目标对话
2. 点击目标对话的名称或条目
3. 系统将加载该对话的历史记录和当前状态

##### 4.1.2.4 输出/结果
- 右侧主聊天区域显示选中对话的全部历史消息
- 对话列表中被选中的对话项高亮显示
- 如果对话关联了文档，右侧可能显示文档相关信息
- 页面URL可能更新为包含对话ID

##### 4.1.2.5 异常处理
| 异常现象 | 可能原因 | 处理方法 |
|---------|---------|---------|
| 点击对话无响应 | 对话数据加载失败 | 刷新页面后重试 |
| 历史消息显示不全 | 网络延迟或分页加载异常 | 滚动查看或等待加载完成 |
| 提示"对话不存在" | 对话已被删除或ID无效 | 从对话列表中移除该条目，创建新对话 |

### 4.2 消息发送与接收

#### 4.2.1 发送文本消息

##### 4.2.1.1 功能概述
向 Agent 发送文本消息，提出文档编写需求、咨询问题或进行多轮对话。

##### 4.2.1.2 前置条件
- 已创建或选中一个对话会话
- 聊天输入框处于可编辑状态

##### 4.2.1.3 操作步骤
1. 在页面底部的消息输入框中，输入您的需求或问题
2. （可选）按 `<Enter>` 键换行，按 `<Shift>+<Enter>` 键发送消息
3. 点击输入框右侧的【发送】按钮或按 `<Enter>` 键发送消息

##### 4.2.1.4 输出/结果
- 用户消息立即显示在聊天区域，带有用户标识
- 输入框清空，准备接收下一条消息
- 系统开始处理消息，可能显示"正在思考..."等状态提示
- Agent 响应将以流式方式逐步显示

##### 4.2.1.5 输入要求
- 消息内容：支持中英文、标点符号、代码片段等
- 长度限制：通常支持长文本输入，具体限制待确认
- 格式要求：纯文本输入，富文本格式可能不被支持

##### 4.2.1.6 异常处理
| 异常现象 | 可能原因 | 处理方法 |
|---------|---------|---------|
| 发送按钮灰色不可用 | 输入框为空或只包含空白字符 | 输入有效内容后重试 |
| 发送后消息未显示 | 网络延迟或前端渲染异常 | 等待片刻，如未恢复则刷新页面 |
| 提示"消息发送失败" | 网络断开或服务异常 | 检查网络连接，重试发送 |

#### 4.2.2 接收 Agent 响应

##### 4.2.2.1 功能概述
查看 Agent 对用户消息的响应，包括文本回答、Skill 调用信息和文档生成结果。

##### 4.2.2.2 操作说明
1. 发送消息后，系统自动开始接收 Agent 响应
2. 响应内容以流式方式逐步显示在聊天区域
3. 响应可能包含：
   - Agent 的文本回答
   - 调用的 Skill 名称和结果
   - 生成的文档内容预览
   - Token 用量统计信息

##### 4.2.2.3 输出/结果
- Agent 消息显示在聊天区域，带有 Agent 标识
- 如果是流式输出，用户可以看到文字逐个出现的效果
- 响应完成后，对话历史自动保存
- 如果生成了文档，会显示文档保存路径和版本信息

##### 4.2.2.4 异常处理
| 异常现象 | 可能原因 | 处理方法 |
|---------|---------|---------|
| 响应中断或停止 | 网络连接不稳定 | 等待重连，或重新发送消息 |
| 响应内容显示乱码 | 编码问题或数据解析异常 | 刷新页面查看历史记录 |
| 长时间无响应 | Agent 处理超时或服务异常 | 检查系统状态，联系管理员 |

### 4.3 对话历史管理

#### 4.3.1 查看对话历史

##### 4.3.1.1 功能概述
查看当前对话的所有历史消息记录，包括用户输入、Agent 响应和相关元数据。

##### 4.3.1.2 操作步骤
1. 切换到目标对话（参考 4.1.2 切换对话）
2. 右侧聊天区域自动显示该对话的全部历史消息
3. 使用鼠标滚轮或触摸板上下滚动查看完整历史
4. （如有分页）滚动到底部可能自动加载更多历史记录

##### 4.3.1.3 输出/结果
- 按时间顺序显示所有消息记录
- 每条消息显示发送者（用户/Agent）、时间和内容
- Skill 调用会以特殊格式标记显示
- 文档生成记录会显示文档链接或路径

##### 4.3.1.4 异常处理
| 异常现象 | 可能原因 | 处理方法 |
|---------|---------|---------|
| 历史记录加载不全 | 分页加载异常或数据量过大 | 尝试刷新页面，或联系管理员调整分页设置 |
| 消息时间显示错误 | 时区设置或时间同步问题 | 检查系统时间设置，此问题通常不影响使用 |
| 特定消息内容缺失 | 数据存储异常或消息被清理 | 如为重要内容，尝试从备份恢复或重新生成 |

#### 4.3.2 重命名对话

##### 4.3.2.1 功能概述
修改对话的名称，便于在对话列表中识别和查找。

##### 4.3.2.2 操作步骤
1. 在左侧对话列表中，找到需要重命名的对话
2. 将鼠标悬停在对话名称上，点击出现的【编辑】图标（通常为铅笔图标）
3. 输入新的对话名称
4. 按 `<Enter>` 键或点击空白处保存
5. 或按 `<Esc>` 键取消重命名

##### 4.3.2.3 输出/结果
- 对话列表中的名称立即更新
- 名称更改自动保存到服务器
- 页面标题可能同步更新（如浏览器标签页显示对话名称）

##### 4.3.2.4 输入要求
- 对话名称：支持中英文、数字、常用符号
- 长度限制：通常有最大长度限制，具体值待确认
- 唯一性：允许重名，建议使用有区分度的名称

##### 4.3.2.5 异常处理
| 异常现象 | 可能原因 | 处理方法 |
|---------|---------|---------|
| 编辑图标不显示 | 界面交互状态异常 | 刷新页面后重试 |
| 重命名后立即恢复原名称 | 保存失败或同步冲突 | 重新执行重命名操作 |
| 提示"名称无效" | 包含非法字符或超长 | 使用更简洁的名称，避免特殊字符 |

#### 4.3.3 删除对话

##### 4.3.3.1 功能概述
永久删除不再需要的对话会话，释放存储空间并清理对话列表。

**警告**：删除操作不可恢复，该对话的所有历史记录、关联的中间状态和上下文信息将永久丢失。如果对话关联了已生成的文档，文档本身不会被删除，但对话与文档的关联记录将丢失。

##### 4.3.3.2 操作步骤
1. 在左侧对话列表中，找到需要删除的对话
2. 将鼠标悬停在对话条目上，点击出现的【删除】图标（通常为垃圾桶图标）
3. 系统弹出确认对话框，提示删除风险
4. 在确认对话框中点击【确定】按钮确认删除
5. 或点击【取消】按钮放弃删除

##### 4.3.3.3 输出/结果
- 对话从左侧列表中立即消失
- 如果删除的是当前正在查看的对话，系统自动切换到另一个对话或新建对话
- 存储空间相应释放

##### 4.3.3.4 异常处理
| 异常现象 | 可能原因 | 处理方法 |
|---------|---------|---------|
| 删除后对话仍显示 | 前端缓存或同步延迟 | 刷新页面查看实际状态 |
| 提示"删除失败" | 权限不足或服务异常 | 检查用户权限，或联系管理员 |
| 误删除重要对话 | 用户操作失误 | 立即联系管理员，查看是否有备份可恢复 |

### 4.4 上下文管理

#### 4.4.1 理解对话上下文

##### 4.4.1.1 功能概述
Agent 自动维护对话的上下文信息，确保在多轮对话中理解用户的连贯意图和需求。

##### 4.4.1.2 功能说明
- **自动上下文维护**：系统自动记录对话历史，作为后续交互的上下文
- **结构化上下文加载**：Agent 可以按模块、按词汇类型精确加载相关项目事实
- **多轮对话理解**：Agent 能够理解指代、省略和基于之前对话的延续需求
- **上下文长度管理**：系统可能自动截断或总结过长的上下文以维持性能

##### 4.4.1.3 用户操作提示
1. 在连续对话中，无需重复之前已提及的信息
2. 可以使用"上面提到的"、"刚才说的"等指代性语言
3. Agent 会基于整个对话历史理解您的当前需求
4. 如需完全重新开始，建议创建新对话而非在原有对话中切换话题

##### 4.4.1.4 注意事项
- 上下文长度有限制，极长的对话历史可能被部分截断
- 切换对话后，上下文自动切换为新对话的历史
- 系统重启或长时间闲置可能影响上下文保持，具体行为待确认

#### 4.4.2 查看上下文相关信息

##### 4.4.2.1 功能概述
查看当前对话上下文中加载的项目事实、Skill调用记录等辅助信息。

##### 4.4.2.2 操作步骤
1. 在对话界面中，查找上下文信息展示区域（通常位于聊天区域侧边或底部）
2. 查看当前加载的模块信息（如 mod-agent、mod-skill 等）
3. 查看已调用的 Skill 列表及其状态
4. 查看相关的项目事实词汇表引用

##### 4.4.2.3 输出/结果
- 显示当前对话上下文中的关键元素
- 帮助用户理解 Agent 的决策依据
- 提供透明化的 AI 交互体验

##### 4.4.2.4 异常处理
| 异常现象 | 可能原因 | 处理方法 |
|---------|---------|---------|
| 上下文信息不显示 | 界面配置隐藏或数据未加载 | 检查界面设置，或刷新页面 |
| 显示的信息过时 | 上下文更新延迟 | 发送新消息触发上下文更新 |
| 信息显示混乱 | 数据格式异常或渲染问题 | 刷新页面，或联系技术支持 |

### 4.5 高级功能

#### 4.5.1 使用 Skill 能力

##### 4.5.1.1 功能概述
Agent 自动调用合适的 Skill 来执行特定任务，如文档生成、代码分析、事实查询等。

##### 4.5.1.2 操作说明
1. 在对话中提出需要特定技能处理的需求
2. Agent 自动识别需求并调度合适的 Skill
3. 在聊天界面中，Skill 调用会以特殊消息格式显示
4. 查看 Skill 执行结果和生成的内容

##### 4.5.1.3 输出/结果
- Skill 调用过程对用户透明，无需手动选择
- Skill 执行结果集成到 Agent 的响应中
- 可能显示 Skill 名称、执行状态和耗时
- 如果涉及文档生成，会显示文档保存信息

##### 4.5.1.4 注意事项
- 不同 Skill 有不同的能力边界和输入要求
- 如果 Agent 未能调用合适的 Skill，可能需要更明确地描述需求
- Skill 执行失败会有相应错误提示

#### 4.5.2 查看 Token 用量

##### 4.5.2.1 功能概述
查看当前对话或单次交互的 Token 消耗情况，了解资源使用状况。

##### 4.5.2.2 操作步骤
1. 在对话界面中，查找 Token 用量显示区域
2. 查看当前消息的 Token 统计
3. 查看累计对话的 Token 使用量
4. （如有）查看不同模型或 API 的用量细分

##### 4.5.2.3 输出/结果
- 显示输入 Token 数和输出 Token 数
- 显示总 Token 消耗量
- 可能显示费用估算或配额使用情况
- 帮助用户优化提示词以减少 Token 消耗

##### 4.5.2.4 异常处理
| 异常现象 | 可能原因 | 处理方法 |
|---------|---------|---------|
| Token 统计不显示 | 功能未启用或界面配置问题 | 检查系统设置，或联系管理员 |
| 统计数值异常 | 计数算法或数据异常 | 刷新页面，如持续异常报告给技术支持 |
| 配额超限提示 | 使用量超过许可限制 | 联系管理员调整配额或优化使用方式 |
