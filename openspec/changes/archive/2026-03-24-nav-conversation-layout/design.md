## Context

当前布局结构为三栏：左侧固定导航（200px）+ 对话侧边栏（210px，仅 Chat tab 下可见）+ 主内容区。对话侧边栏占据固定宽度，在非 Chat tab 下完全隐藏，布局存在跳变感。主内容区宽度随 tab 切换而变化，体验不一致。

对话的默认命名为时间戳格式（"对话 2024-01-15 14:30"），无法通过名称快速识别对话内容，用户需要点击进入才能判断。

## Goals / Non-Goals

**Goals:**
- 将对话记录列表移入左侧导航栏，消除独立侧边栏，统一主内容区宽度
- 对话记录按日期分组展示（今天 / 昨天 / 更早）
- 去掉顶部"+ 新对话"按钮，改为导航区的"新对话"操作
- 对话完成首轮后，自动调用 LLM 生成语义化标题替换默认名称

**Non-Goals:**
- 不改变对话的数据结构和存储方式
- 不实现对话搜索/筛选功能
- 不修改 Chat 主内容区的消息展示逻辑
- 不实现对话标题的手动编辑功能（本期）

## Decisions

### 决策 1：对话列表嵌入导航栏而非单独侧边栏

导航栏宽度扩展为 220px，菜单项下方区域展示对话记录，使用 `overflow-y: auto` 滚动。移除独立 `sidebar-panel`，主内容区始终占满剩余宽度。

**替代方案考虑**：保留独立侧边栏但改为可折叠 → 增加交互复杂度，MVP 阶段不必要。

### 决策 2：日期分组策略

分三组：今天 / 昨天 / 更早。在前端按 `updated_at` 字段计算分组，无需后端改动。分组标题使用小字 uppercase 样式与菜单项区分。

### 决策 3：自动命名触发时机

在 WebSocket `done` 事件触发后（首轮对话完成），前端检测到对话名称仍为默认格式时，向后端发起异步命名请求。后端使用当前对话的首轮 user_input + agent_response 调用 LLM（简短 prompt），返回 ≤20 字的中文标题，然后更新对话记录。

**替代方案考虑**：在后端 done 事件内部同步生成 → 增加首轮响应延迟，不采用。

**LLM 调用说明**：使用系统默认 LLM 配置，温度设为 0.3（降低随机性），prompt 为 "请为以下对话生成一个不超过15字的中文标题，只返回标题文本：\n用户：{input}\nAI：{response_summary}"。

### 决策 4："新对话"入口位置

在导航栏对话记录区顶部放置"新对话"按钮（小型，ghost style）。同时保留 Chat 头部的"新对话"按钮作为备用（但样式降级）。

### 决策 5：导航栏三区垂直布局

导航栏采用 `display: flex; flex-direction: column` 并分为三个明确区域，通过空间隔离而非边框线分隔：

```
┌─────────────────────┐
│  Logo               │  ← 固定，不滚动
│  ─────────────────  │
│  对话 (active)      │  ← 顶部菜单区（flex-shrink: 0）
│  Skill              │
│  文档               │
│  项目事实           │
│  ─────────────────  │
│  新对话  [按钮]     │  ← 中间对话记录区（flex: 1, overflow-y: auto）
│  ▸ 今天             │
│    用户认证需求文档 │
│  ▸ 昨天             │
│    API接口设计      │
│  ─────────────────  │
│  ⚙ LLM 配置        │  ← 底部设置区（flex-shrink: 0）
└─────────────────────┘
```

**分隔方式**：三区之间使用 `margin-top: auto`（将底部区域推到底部）+ 适当的 padding 间距区分，不使用 1px 分割线（遵循 Editorial Light 设计规范）。顶部菜单区和底部设置区固定，中间对话列表区 `flex: 1; overflow-y: auto` 独立滚动。

**LLM 配置入口**：从顶部 Tab 菜单移到底部区域，样式为 ghost nav item，与顶部菜单项视觉一致但位置固定在底部，代表"全局设置"语义。顶部 Tab 列表中去除 LLM 配置项。

## Risks / Trade-offs

- **[LLM 命名失败]** → 保留时间戳名称，不阻断用户流程；失败静默处理
- **[导航栏对话列表过长]** → 设置 max-height + overflow-y: auto，菜单项固定不滚动，仅对话列表区域滚动
- **[自动命名增加 LLM 调用成本]** → 使用轻量 prompt（<200 tokens），可接受
- **[导航宽度增加]** → 从 200px 扩展到 220-240px，主内容区相应缩小，整体影响较小
