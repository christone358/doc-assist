## MODIFIED Requirements

### Requirement: 项目事实信息支持渐进式按需访问
项目事实信息 SHALL 支持渐进式访问——Agent 可以从项目概览开始，根据实际需要逐步获取更详细的数据，直到满足当前写作任务的需要为止。Agent 不需要一次性加载全部数据。

#### Scenario: 从概览开始逐步深入
- **WHEN** Agent 需要了解项目事实信息时
- **THEN** Agent SHALL 能够先获取概览信息定位目标，再根据需要获取更详细的内容，而非一次性加载所有数据

#### Scenario: 按写作目标过滤相关事实
- **WHEN** Agent 需要与当前写作目标相关的事实信息时
- **THEN** Agent SHALL 能够将查询范围限定在与写作目标关联的内容（例如特定模块、类、包或用例），不加载与当前任务无关的数据

#### Scenario: 以合适的概览作为导航起点
- **WHEN** Agent 开始执行资料收集任务时
- **THEN** Agent SHALL 根据 Skill 的需求，优先获取适合当前任务的项目概览信息（例如：需求类文档以模块清单为起点，软件设计类文档可能以包结构或类清单为起点），再逐步深入获取详细数据
