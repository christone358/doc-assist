## ADDED Requirements

### Requirement: 模块档案是唯一人工维护单元
系统 SHALL 以模块档案作为项目知识信息的唯一人工维护单元。产品、研发和后续维护人员 MUST 在同一模块档案中逐步补充模块描述、功能点、API 清单、页面原型、包/类和依赖模块等信息，而不是并行维护多套权威事实源。

#### Scenario: 产品经理先创建最小模块档案
- **WHEN** 产品经理首次定义一个新功能模块时
- **THEN** 系统 SHALL 允许只填写模块名称、功能描述和初始功能点，即可形成有效的模块档案

#### Scenario: 研发在同一模块档案中补充技术信息
- **WHEN** 研发人员为既有模块补充 API、页面原型、包或类信息时
- **THEN** 系统 SHALL 将这些内容追加到同一模块档案中，而不是要求研发在独立事实源中重复录入

#### Scenario: 模块档案允许逐步完善
- **WHEN** 模块尚未具备完整的 API、原型或类包信息时
- **THEN** 系统 SHALL 允许该模块档案继续被保存和使用，并把缺失章节视为“待完善”而不是结构错误

### Requirement: 模块档案使用固定骨架且面向自然语言维护
每个模块档案 SHALL 使用统一、易读的文档骨架，至少覆盖基本信息、功能描述、功能点、API 清单、页面/原型、包/类、依赖模块和备注等章节。用户 MUST 以自然语言名称和描述维护内容，系统 MUST NOT 要求用户手工输入机器内部标识作为日常维护前提。

#### Scenario: 固定章节骨架
- **WHEN** 用户创建或编辑模块档案时
- **THEN** 系统 SHALL 提供固定章节骨架，使不同模块档案具有一致的信息布局

#### Scenario: 用户以自然语言维护模块信息
- **WHEN** 用户录入模块、功能点或 API 信息时
- **THEN** 系统 SHALL 允许用户直接使用业务名称、页面名称、接口名称和类名进行维护，而不是要求用户填写显式模块 ID 或交叉引用 ID

#### Scenario: 原型按页面名称维护模块关联
- **WHEN** 用户在模块档案中维护页面 / 原型信息时
- **THEN** 系统 SHALL 允许用户只维护与模块相关的页面名称或页面说明，而不是要求用户为每个模块拆分单独的 HTML 原型文件

### Requirement: Markdown 与 Excel 维护必须收敛到同一事实源
系统 SHALL 支持 Markdown 直接维护和 Excel 导入两种入口，但这些入口最终 MUST 收敛为同一套模块档案。任何派生视图、缓存、索引或导入中间产物 MUST NOT 成为与模块档案并列的权威事实源。

#### Scenario: Excel 导入收敛到模块档案
- **WHEN** 用户通过 Excel 导入模块、功能点或 API 信息时
- **THEN** 系统 SHALL 将导入结果转换并写入对应模块档案，而不是生成独立的长期维护格式

### Requirement: 原型资源支持集中存放
系统 SHALL 支持将 Axure 等工具导出的整套原型资源集中存放，并通过模块档案中的页面名称列表建立模块与原型页之间的关联。

#### Scenario: 集中存放 Axure 原型包
- **WHEN** 用户维护由 Axure 导出的完整 HTML 原型包时
- **THEN** 系统 SHALL 允许该原型包作为集中资源整体存放，而不是要求用户按模块拆分原型文件

#### Scenario: 模块与原型页建立轻量关联
- **WHEN** 模块档案中填写了页面名称列表
- **THEN** 系统 SHALL 将这些页面名称视为该模块关联的原型页，并允许后续通过派生索引或页面名匹配进行浏览和检索

### Requirement: 系统自动派生内部标识和关联索引
系统 SHALL 基于模块档案自动派生稳定的内部标识、模块名称/别名索引以及模块与功能点、API、页面原型、包/类之间的关联索引，供检索、缓存和 Agent 读取使用。派生结果 MAY 被缓存，但用户 MUST NOT 被要求手工维护这些派生数据。

#### Scenario: 自动生成稳定内部标识
- **WHEN** 用户创建新模块档案时
- **THEN** 系统 SHALL 自动为该模块生成稳定内部标识，并在模块改名后保持历史引用可追踪

#### Scenario: 自动生成模块关系索引
- **WHEN** 模块档案中存在功能点、API、页面原型、包/类和依赖模块信息时
- **THEN** 系统 SHALL 自动生成这些要素与模块之间的关联索引，供 Agent 和查询接口使用
