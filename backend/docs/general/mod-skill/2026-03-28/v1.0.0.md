## NextAgent Doc Assistant 技能管理模块用户使用手册

### 第4章 软件操作指南

#### 4.1 技能管理模块

技能管理模块是系统的核心扩展框架，负责管理所有可用的“技能”（Skill）。技能是系统执行特定任务（如生成文档、分析代码）的能力单元。本模块允许管理员查看、启用、禁用系统内置技能，并支持用户扩展自定义技能。

**模块入口**：`需产品确认，通常在系统管理或技能中心菜单下。`

##### 4.1.1 查看技能列表

**4.1.1.1 功能概述**
本功能用于查看系统中所有已注册的技能，包括其名称、描述、状态（启用/禁用）等基本信息，帮助用户了解系统当前具备的能力。

**4.1.1.2 前置条件**
- 用户已成功登录 NextAgent Doc Assistant 系统。
- 用户拥有访问技能管理模块的权限（通常为管理员角色）。

**4.1.1.3 操作步骤**
1.  登录系统后，在主菜单栏选择 **【系统管理】** > **【技能管理】**。`（菜单路径待确认）`
2.  系统将跳转至“技能列表”页面。
3.  页面以表格形式展示所有技能，通常包含以下列：`（界面字段待确认）`
    - **技能名称**：技能的标识名称。
    - **技能描述**：对该技能功能的简要说明。
    - **状态**：显示“已启用”或“已禁用”。
    - **操作**：提供对该技能进行管理的按钮，如“启用/禁用”、“详情”。

**4.1.1.4 输出/结果**
- 成功加载后，页面将显示完整的技能列表。
- 用户可以通过列表了解每个技能的基本信息和当前可用状态。

**4.1.1.5 异常处理**
| 异常现象 | 可能原因 | 处理方法 |
| :--- | :--- | :--- |
| 页面提示“暂无数据”或列表为空。 | 1. 系统未成功加载任何技能。<br>2. 当前过滤器筛选结果为空。 | 1. 检查系统服务是否正常，技能目录配置是否正确。<br>2. 清除可能的筛选条件。 |
| 页面提示“权限不足”。 | 当前登录账号无权限访问此模块。 | 联系系统管理员获取相应权限。 |

##### 4.1.2 启用/禁用技能

**4.1.2.1 功能概述**
本功能允许管理员控制单个技能的可用性。禁用某个技能后，Agent 在调度时将不会调用该技能。

**4.1.2.2 前置条件**
- 已进入“技能列表”页面。
- 目标技能存在且状态明确。

**4.1.2.3 操作步骤**
1.  在“技能列表”页面，找到需要操作的目标技能。
2.  在目标技能所在行的“操作”列，点击 **【禁用】** 按钮（若技能当前为启用状态）或 **【启用】** 按钮（若技能当前为禁用状态）。`（按钮文案待确认）`
3.  系统可能会弹出确认对话框，提示操作影响（例如：“禁用后，系统将无法使用此技能”）。
4.  在确认对话框中，点击 **【确定】** 按钮以执行操作。

**4.1.2.4 输出/结果**
- 操作成功后，页面技能列表中该技能的“状态”列将立即更新为“已禁用”或“已启用”。
- 系统可能给出短暂的成功提示，如“技能状态已更新”。`（提示文案待确认）`
- 状态变更即刻生效。对于已禁用的技能，后续的用户请求将不会被分配至该技能执行。

**4.1.2.5 异常处理**
| 异常现象 | 可能原因 | 处理方法 |
| :--- | :--- | :--- |
| 点击按钮无反应或状态未更新。 | 1. 网络通信异常。<br>2. 后端服务处理失败。 | 1. 检查网络连接，刷新页面后重试。<br>2. 查看系统日志或联系技术支持。 |
| 提示“操作失败，技能不存在”。 | 技能可能已被删除或配置文件损坏。 | 检查技能配置文件或联系系统管理员。 |

**4.1.2.6 警告/注意**
- **注意**：禁用核心技能（如文档生成类技能）可能会影响系统的主要功能，请谨慎操作。
- **注意**：状态变更实时生效，无需重启服务。

##### 4.1.3 查看技能详情

**4.1.3.1 功能概述**
本功能用于查看特定技能的详细元信息，包括其能力描述、输入输出要求、配置参数等，帮助用户深入理解该技能的作用和使用边界。

**4.1.3.2 前置条件**
- 已进入“技能列表”页面。

**4.1.3.3 操作步骤**
1.  在“技能列表”页面，找到需要查看详情的技能。
2.  在该技能所在行的“操作”列，点击 **【详情】** 或 **【查看】** 按钮。`（按钮文案待确认）`
3.  系统将打开一个侧边栏或新页面，展示该技能的详细信息。

**4.1.3.4 输出/结果**
- 页面展示技能的完整元信息，内容解析自该技能的 `skill.md` 文件，可能包括：`（详情字段待确认）`
    - **技能标识符 (ID)**：系统内部调用的唯一标识。
    - **技能名称**：显示名称。
    - **详细描述**：比列表更详尽的功能说明。
    - **能力边界**：明确说明该技能擅长处理和不擅长处理的任务类型。
    - **输入/输出示例**：展示调用该技能所需的典型输入和预期输出格式。
    - **版本**：技能的版本号。

**4.1.3.5 异常处理**
| 异常现象 | 可能原因 | 处理方法 |
| :--- | :--- | :--- |
| 点击详情后页面无内容或报错。 | 技能的元信息文件 (`skill.md`) 缺失或格式错误。 | 联系技能开发者或系统管理员检查该技能的配置文件。 |

##### 4.1.4 扩展自定义技能（高级功能）

**4.1.4.1 功能概述**
本功能面向开发者或高级用户，允许通过编写符合规范的技能文件并放置到指定目录，来扩展系统的能力。系统会自动发现并加载新技能。

**4.1.4.2 前置条件**
- 用户具有服务器文件系统的访问权限（此操作通常不通过Web UI完成）。
- 了解 Skill 框架的开发规范。

**4.1.4.3 操作步骤**
`（此部分为系统级操作，非Web界面操作）`
1.  **开发技能**：按照 `Skill 框架模块` 定义的接口和规范，编写技能执行逻辑和 `skill.md` 元信息文件。
2.  **放置文件**：将技能相关的文件包放置到系统配置的技能加载目录下（例如 `./skills/`）。`（目录路径待确认）`
3.  **触发加载**：系统会在启动时自动扫描目录并加载技能。对于已运行的系统，可能需要通过 **【刷新技能列表】** 功能或重启服务来使新技能生效。`（Web UI上是否有刷新按钮待确认）`

**4.1.4.4 输出/结果**
- 操作成功后，新技能将出现在“技能列表”中，状态默认为“已启用”。
- Agent 在处理用户请求时，可以将任务调度给新添加的技能。

**4.1.4.5 异常处理**
| 异常现象 | 可能原因 | 处理方法 |
| :--- | :--- | :--- |
| 新技能未出现在列表中。 | 1. `skill.md` 文件格式不符合规范。<br>2. 技能文件未放在正确目录。<br>3. 系统未重新加载技能列表。 | 1. 检查 `skill.md` 文件的语法和必填字段。<br>2. 确认技能存放目录。<br>3. 尝试在管理界面执行“刷新”操作或重启服务。 |
| 新技能加载失败，状态为“错误”。 | 技能的逻辑代码存在bug或依赖缺失。 | 查看系统错误日志，根据报错信息修复技能代码。 |

**4.1.4.6 警告/注意**
- **警告**：添加未经测试的自定义技能可能存在稳定性风险，建议先在测试环境中验证。
- **注意**：技能文件的命名和结构必须严格遵守框架规范，否则无法被正确识别和加载。
