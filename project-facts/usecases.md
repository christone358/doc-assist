# 用例清单

NextAgent Doc Assistant 系统支持的所有主要用例。

---

## Agent 理解和调度

### UC-001: Agent 理解用户文档编写需求
- **模块**: mod-agent
- **角色**: 用户
- **描述**: 用户用自然语言描述文档编写需求，Agent 理解意图并确定任务类型（新增编写或精准修改）。

### UC-002: Agent 调度合适的文档编写 Skill
- **模块**: mod-agent
- **角色**: 系统
- **描述**: Agent 根据用户意图，从已加载的 Skill 中选择最合适的 Skill 执行文档编写任务。

### UC-003: Agent 执行精准文档修改
- **模块**: mod-agent
- **角色**: 用户
- **描述**: 用户指定某部分需要修改，Agent 基于上一版本进行精准修改并展示 diff。

---

## 用户交互

### UC-004: 用户通过 Web UI 提交文档需求
- **模块**: mod-webui
- **角色**: 用户
- **描述**: 用户在 Web 界面输入自然语言需求，系统实时展示 Agent 处理过程和生成结果。

### UC-005: 用户与 Agent 进行多轮对话交互
- **模块**: mod-conv
- **角色**: 用户
- **描述**: 用户通过多轮对话逐步完善文档需求，Agent 维护对话上下文并根据反馈调整输出。

### UC-006: 用户查看和下载生成的文档
- **模块**: mod-doc-ver
- **角色**: 用户
- **描述**: 用户在对话过程中查看生成文档的路径，并可访问或下载已保存的文档文件。

---

## 文档管理

### UC-007: 系统自动保存文档版本
- **模块**: mod-doc-ver
- **角色**: 系统
- **描述**: 每次文档生成完成后，系统按 `docs/[type]/[name]/[date]/[version].md` 结构自动保存，并记录到对话中。

### UC-008: 用户查看文档版本历史
- **模块**: mod-doc-ver
- **角色**: 用户
- **描述**: 用户可以查看某文档的所有历史版本列表，了解各版本的生成时间和对应对话。

### UC-009: 用户对文档进行版本比较
- **模块**: mod-doc-ver
- **角色**: 用户
- **描述**: 用户可以对比两个版本之间的差异，以 diff 形式查看修改内容。

---

## Skill 管理

### UC-010: 用户自定义和扩展文档编写 Skill
- **模块**: mod-skill
- **角色**: 用户
- **描述**: 用户创建新的 Skill 目录并编写 skill.md，系统重启后自动识别新 Skill。

### UC-011: 系统自动发现和加载 Skill
- **模块**: mod-skill
- **角色**: 系统
- **描述**: Agent 启动时扫描 skills 目录，解析所有 skill.md 的元信息，建立 Skill 能力索引。

### UC-012: 系统验证 Skill 的有效性
- **模块**: mod-skill
- **角色**: 系统
- **描述**: 加载 Skill 时验证 skill.md 必需字段是否完整，无效 Skill 跳过并记录警告日志。

---

## 项目事实信息

### UC-013: 用户维护项目事实信息
- **模块**: mod-facts
- **角色**: 用户
- **描述**: 用户按规范格式编写和更新 project-facts/ 目录下的清单文件，为 Agent 提供项目知识。

### UC-014: Agent 加载项目上下文
- **模块**: mod-facts
- **角色**: 系统
- **描述**: Agent 根据 Skill 的上下文需求和目标模块，从 project-facts 中精确加载相关条目。

### UC-015: Agent 基于事实信息生成更准确的文档
- **模块**: mod-agent
- **角色**: 系统
- **描述**: Agent 将加载的项目上下文注入 LLM prompt，使生成的文档内容与项目实际情况一致。

---

## LLM 配置

### UC-016: 用户配置和管理 LLM 模型
- **模块**: mod-llm
- **角色**: 用户
- **描述**: 用户在系统配置中添加、编辑或删除 LLM 模型配置（API 地址、Token、模型名、参数等）。

### UC-017: Agent 选择合适的 LLM 模型执行任务
- **模块**: mod-llm
- **角色**: 系统
- **描述**: Agent 使用配置的默认模型执行任务，用户可在运行时切换到其他已配置的模型。

### UC-018: 系统支持多个 LLM 模型之间的切换
- **模块**: mod-llm
- **角色**: 用户
- **描述**: 用户可以在对话过程中切换到不同的 LLM 模型，后续请求使用新选择的模型。
