# 用例清单

## 项目概述
NextAgent Doc Assistant 是一个基于 AI Agent 的智能文档编写工具。本清单列举系统支持的所有主要用例。

## Agent 核心功能

### 理解和调度
- UC-001: Agent理解用户文档编写需求
- UC-002: Agent调度合适的文档编写Skill
- UC-003: Agent执行精准文档修改

### 用户交互
- UC-004: 用户通过Web UI提交文档需求
- UC-005: 用户与Agent进行多轮对话交互
- UC-006: 用户查看和下载生成的文档

## 文档管理
- UC-007: 系统自动保存文档版本
- UC-008: 用户查看文档版本历史
- UC-009: 用户对文档进行版本比较

## Skill管理
- UC-010: 用户自定义和扩展文档编写Skill
- UC-011: 系统自动发现和加载Skill
- UC-012: 系统验证Skill的有效性

## 项目事实信息
- UC-013: 用户维护项目事实信息
- UC-014: Agent查询和推荐项目事实信息
- UC-015: Agent基于事实信息生成更准确的文档

## LLM配置
- UC-016: 用户配置和管理LLM模型
- UC-017: Agent选择合适的LLM模型执行任务
- UC-018: 系统支持多个LLM模型之间的自动切换
