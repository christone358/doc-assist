# 项目事实信息初始化说明

当前 `project-facts/` 已重置为全新初始化状态。

## 目录结构

```text
project-facts/
├─ README.md
├─ modules/                          # 模块档案人工维护目录
│  └─ 模块档案模板.md
├─ prototypes/                       # 原型集中存放目录
│  └─ README.md
└─ generated/                        # 系统派生目录
   └─ views/
      └─ module-details/
```

## 初始化原则

- 模块档案是唯一人工维护层
- 每个模块一份 Markdown 档案
- 模块档案文件命名规则为 `系统-子系统-模块.md`，若无子系统则使用 `系统-模块.md`
- 所属系统为必填项，所属子系统为可选项
- 每个模块可维护独立的用例信息
- 每个模块可包含多个子模块，每个子模块下维护多个功能点
- 原型资源统一放在 `prototypes/`
- `generated/` 由系统生成，不手工维护

## 从这里开始

1. 复制 `modules/模块档案模板.md`
2. 重命名为目标模块名称
3. 填写系统、可选子系统、功能描述、用例信息、子模块和功能点
4. 后续再补 API、页面 / 原型、包 / 类和依赖模块
