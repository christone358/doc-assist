# 脆弱性管理

## 基本信息
- 所属系统: 业务保障管理系统
- 所属子系统: 资产脆弱性管理

## 功能描述
面向资产管理员，提供脆弱性全生命周期（发现-修复-验证）管理，提高漏洞修复率
