# 测试方案文档编写



本 Skill 帮助用户编写测试方案文档，包括测试策略、测试用例和测试环境规划。

## 能力范围

### 支持
- 编写功能测试用例
- 性能测试方案
- 边界条件和异常测试用例
- 从需求规格提取测试点

### 不支持
- 自动执行测试
- 生成测试脚本代码

## 工作原理

编写测试方案时，本 Skill 需要了解目标模块的用例信息（用户故事、主流程、异常流程、前后置条件），这些是测试用例设计的直接来源。同时需要了解功能模块描述，以理解模块边界和关键特性，确保测试覆盖所有核心功能点。

如果需要对接口进行测试，还需要参考接口清单，了解 API 的输入参数、响应格式和错误码，从而设计针对接口的测试用例。

## 输出规范

生成的测试方案文档包含：
1. 文档信息
2. 测试概述（目标、范围、策略）
3. 测试环境
4. 功能测试用例
5. 非功能测试方案（性能、安全等）
6. 测试流程和时间计划
