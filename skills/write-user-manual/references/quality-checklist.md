# 用户使用手册质量检查清单

用于在完成用户手册，尤其是第 4 章“软件操作指南”后进行快速复核。

## 一、结构与组织

- [ ] `STR-001` 第 4 章按功能模块或经确认的业务场景组织，无混乱交叉
- [ ] `STR-002` 目录层级不超过三级
- [ ] `STR-003` 每个功能模块下的操作单元命名清晰、边界独立
- [ ] `STR-004` 所有目标功能点都有对应操作说明，无明显遗漏

## 二、操作单元完整性

- [ ] `UNIT-001` 每个操作单元都有“功能概述”
- [ ] `UNIT-002` 每个操作单元都有“操作步骤”
- [ ] `UNIT-003` 每个操作单元都有“输出/结果”
- [ ] `UNIT-004` 每个操作单元都有“异常处理”
- [ ] `UNIT-005` 需要前置条件的操作已明确写出前置条件
- [ ] `UNIT-006` 涉及高风险动作的操作已写出“警告”或“注意”

## 三、步骤可操作性

- [ ] `STEP-001` 每步操作按时间顺序编号
- [ ] `STEP-002` 每一步只描述一个明确动作
- [ ] `STEP-003` 操作入口清晰，用户能找到菜单或页面路径
- [ ] `STEP-004` 输入项已注明必填、格式限制、长度限制或取值范围
- [ ] `STEP-005` 分支场景已分别说明
- [ ] `STEP-006` 仅依据文档即可复现操作

## 四、界面与术语一致性

- [ ] `UI-001` 按钮、菜单、字段、对话框名称与实际界面一致
- [ ] `UI-002` 界面元素引用格式统一
- [ ] `UI-003` 同一概念在全文使用统一术语
- [ ] `UI-004` 未混入接口、数据库、脚本等实现术语

## 五、结果与异常

- [ ] `RES-001` 成功结果写明系统提示信息
- [ ] `RES-002` 成功结果写明页面变化或数据变化
- [ ] `RES-003` 成功结果写明操作完成后的后续状态
- [ ] `EXC-001` 异常处理覆盖主要高频错误
- [ ] `EXC-002` 每个异常项都包含可能原因
- [ ] `EXC-003` 每个异常项都包含用户可执行的处理方法

## 六、截图与警示

- [ ] `PIC-001` 关键界面步骤已引用截图，或明确标记截图待补充
- [ ] `PIC-002` 截图编号与正文引用一致
- [ ] `WARN-001` 删除、禁用、权限变更、覆盖导入等操作已使用醒目标识
- [ ] `WARN-002` 警示内容已说明风险对象、影响范围和注意事项

## 七、语言规范

- [ ] `LANG-001` 全文使用主动语态
- [ ] `LANG-002` 全文主要使用祈使句
- [ ] `LANG-003` 未出现模糊词，如“适当”“快速”“相关逻辑”“系统自动处理”等
- [ ] `LANG-004` 未出现第一人称或开发者口吻
- [ ] `LANG-005` 面向终端用户表达，易懂且可执行

## 八、待确认项控制

- [ ] `TODO-001` 缺失事实已明确标记为 `待补充` 或 `需确认`
- [ ] `TODO-002` 未编造按钮名、字段规则、提示文案或异常现象
- [ ] `TODO-003` 待确认项范围明确，不影响已确认内容的可读性
