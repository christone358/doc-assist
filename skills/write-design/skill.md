# 软件设计方案文档编写



本 Skill 帮助用户编写软件设计方案文档，覆盖系统架构、模块设计、接口规范和数据模型。

## 能力范围

### 支持
- 编写新的技术设计文档
- 基于已有版本精准修改
- 从项目事实信息中提取架构和接口说明
- 生成模块交互和依赖关系描述

### 不支持
- 生成实际代码
- 自动检查设计合理性

## 工作原理

编写软件设计方案时，本 Skill 需要了解目标模块的功能描述（模块职责、关键特性、与其他模块的依赖关系），以及类包清单（核心类的职责、主要方法和属性）。功能模块描述是设计的出发点，类包清单是详细设计的主体内容，两者都是必需的。

在描述接口规范时，需要参考接口清单，了解系统对外或模块间的 API 定义。如果有原型界面，可以用于理解界面层的技术要求和交互复杂度，对设计决策有参考价值。

## 输出规范

生成的设计方案文档包含：
1. 文档信息
2. 设计概述（目标、范围、约束）
3. 架构设计
4. 模块详细设计
5. 接口设计
6. 数据模型
7. 部署方案（可选）
