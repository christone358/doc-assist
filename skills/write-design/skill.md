# 软件设计方案文档编写



本 Skill 帮助用户编写软件设计方案文档，覆盖系统架构、模块设计、接口规范和数据模型。

## 能力范围

### 支持
- 编写新的技术设计文档
- 基于已有版本精准修改
- 从项目事实信息中提取架构和接口说明
- 生成模块交互和依赖关系描述

### 不支持
- 生成实际代码
- 自动检查设计合理性

## 工作原理

编写软件设计方案时，本 Skill 主要依赖两类核心事实：

1. **功能模块描述（modules）**：目标模块的职责、关键特性、与其他模块的依赖关系。这是设计的出发点，必须加载。
2. **类包设计（classes）**：核心类的职责、主要方法和属性、包结构。这是详细设计的主体内容，必须加载。

在描述接口规范时，需要参考**接口清单（interfaces）**，了解系统对外或模块间的 API 定义，是接口设计章节的必要依据。

如果有**原型界面（prototypes）**，可用于理解界面层的技术要求和交互复杂度，对前端模块的设计决策有参考价值。

**推荐加载顺序**：先通过 get_fact_overview("modules") 定位目标模块，再通过 get_fact_detail 加载类包设计（fact_type="classes"）和接口定义（fact_type="interfaces"），功能描述通过模块概览获取。

## 输出规范

生成的设计方案文档包含：
1. 文档信息
2. 设计概述（目标、范围、约束）
3. 架构设计
4. 模块详细设计
5. 接口设计
6. 数据模型
7. 部署方案（可选）
