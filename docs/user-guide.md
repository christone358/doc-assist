# 用户使用指南

## 快速开始

### 启动系统

```bash
# 方式一：一键启动（前端 + 后端）
./start.sh

# 方式二：Docker Compose
docker compose up
```

系统启动后，浏览器访问 `http://localhost:5173`。

---

## 界面介绍

左侧导航栏包含 5 个功能区：

| 标签 | 功能 |
|------|------|
| 💬 对话 | 与 Agent 交互，编写和修改文档 |
| 🔧 Skill | 查看已安装的文档编写 Skill |
| 📁 文档 | 浏览生成的文档和版本历史 |
| 🗂 事实信息 | 浏览项目事实信息（模块档案聚合视图）|
| ⚙️ LLM 配置 | 管理 LLM 模型配置 |

---

## 第一步：配置 LLM 模型

在开始使用前，必须配置至少一个 LLM 模型。

1. 点击「⚙️ LLM 配置」
2. 点击「添加配置」
3. 选择服务商（DeepSeek 或 QWen），填写模型名称、API 地址和 Token
4. 点击「测试连接」确认可用
5. 保存后设为默认

详见：[LLM 配置指南](./llm-config-guide.md)

---

## 第二步：编写新文档

### 基本流程

1. 点击左上角「💬 对话」
2. 在底部输入框输入需求，例如：
   > "帮我为用户认证模块编写需求规格文档"
3. Agent 会分析需求，选择合适的 Skill，并开始生成
4. 生成完成后，文档路径显示在对话中，可在「📁 文档」查看

### 多轮迭代

在同一对话中继续输入，可以逐步完善文档：

```
用户：帮我写用户登录功能的需求文档
Agent：[生成初稿]

用户：请补充异常处理场景
Agent：[补充后输出新版本]

用户：密码规则改为8位以上
Agent：[精准修改后输出新版本]
```

每次修改都会保存为新的版本，可以通过「📁 文档」查看完整版本历史。

---

## 第三步：修改已有文档

当项目需求发生变化时：

1. 在对话中明确告知修改意图，例如：
   > "修改登录功能的需求，把密码最小长度改为 12 位"
2. Agent 会加载最新版本作为基础，进行精准修改
3. 修改后的文档保存为新版本

---

## 查看文档版本历史

1. 点击「📁 文档」
2. 在文档列表找到目标文档
3. 点击版本号查看历史版本
4. 可复制文档路径，在本地文件管理器中打开

文档存储路径格式：
```
docs/[类型]/[文档名]/[日期]/v[版本].md
```

---

## 浏览项目事实信息

1. 点击「🗂 事实信息」
2. 可按层级（清单层 / 核心层 / 设计层）过滤
3. 支持关键词搜索
4. 点击条目查看详细内容

---

## 常见问题

**Q：对话没有响应**
A：检查 LLM 配置是否正确，使用「测试连接」功能验证 API 可用性。

**Q：生成的文档内容不准确**
A：可以在对话中追加更详细的需求描述，或添加项目事实信息后重试。

**Q：如何保存对话记录？**
A：对话记录自动保存。在「💬 对话」左侧边栏可查看历史对话，点击可恢复上下文。

**Q：Skill 列表为空**
A：需要在 `skills/` 目录下安装 Skill。参考 [Skill 开发指南](../skills/SKILL_DEVELOPMENT_GUIDE.md)。

**Q：文档在哪里保存？**
A：所有文档保存在项目根目录的 `docs/` 文件夹下，按类型和日期分类存储。
