# 项目文档

本目录用于存放 NextAgent Doc Assistant 生成的项目文档。

## 目录结构

```
docs/
├── requirements/     # 需求规格文档
├── design/          # 设计文档
├── api/             # API 文档
├── test/            # 测试文档
└── user-guide/      # 用户指南
```

## 文档规范

### 文件命名
- 文件名使用中文，格式：`[文档类型]-[文档名称]-v[版本号].md`
- 例：`需求规格-用户认证-v1.0.0.md`

### 文件结构
每个文档应包含以下部分：
1. 文档标题和元数据（创建日期、版本、作者等）
2. 目录（Table of Contents）
3. 正文内容
4. 附录（如需）

### 版本管理
- 使用语义版本号：vX.Y.Z
- X：主版本（功能大幅变更）
- Y：次版本（新增功能）
- Z：修订号（修复和微小改进）

## 生成流程

项目文档由 NextAgent Doc Assistant 自动生成。用户通过 Web UI 与 Agent 交互，描述文档需求，Agent 调度合适的 Skill 生成文档。

### 新增文档
1. 在 Web UI 输入文档需求
2. Agent 理解需求并调度相关 Skill
3. Skill 生成文档并保存到该目录

### 修改文档
1. 在 Web UI 加载已有文档版本
2. Agent 基于该版本进行修改
3. 生成新版本（版本号自动递增）
